# Simulador de Espectrofotómetro UV-Vis: Práctica Completa

Simulador interactivo y didáctico de laboratorio para espectrofotometría UV-Vis (Lan-Optics).

🔗 **Acceso directo en línea:** [https://choppecin.github.io/espectrofotometro/](https://choppecin.github.io/espectrofotometro/)

## Características
- **13 pasos guiados** interactivos con retroalimentación en tiempo real.
- **Interacción Drag & Drop:** Arrastra cubetas entre la gradilla, la mano y el portacubetas.
- **Simulación física y óptica:** Ley de Lambert-Beer, selección de lámpara (Tungsteno y Deuterio), calibración de cero y Dark Current (0% T).
- **Modos de medida:** Modo Basic (Absorbancia y Transmitancia) y Cuantitativo.
- **Generación de informe e impresión analítica:** Evaluación de buenas prácticas de laboratorio con puntuación final.
